# Experiment A3 protocol

We study how the number of block Lewis fixed-point updates needed to reach a fixed multiplicative residual threshold varies with $p>2$ on matrices partitioned into multi-row blocks.

## Matrix and block family

We generate 50 matrices $A\in\mathbb{R}^{100\times20}$ with independent standard Gaussian entries. Each matrix is partitioned into $k=20$ consecutive blocks of five rows, so $A\_i\in\mathbb{R}^{5\times20}$.

We use development seed 4000 only for implementation checks. The final matrices use seeds 4001-4050 and are generated by

```np.random.default_rng(seed).standard_normal((100, 20))
```

The final experiment reuses each matrix across the same 15 values of $p$: `3, 4, 5.7, 7.3, 10.8, 14.2, 19.6, 27.9, 32, 38.4, 54.1, 64, 74.8, 98.6, 127.3`.

## Block Lewis iteration

For $r=1-2/p$, we write $G(w)=\sum\_i w\_i^r A\_i^\top A\_i$ and apply the block update $w\_i^+=w\_i^r\operatorname{tr}(A\_iG(w)^{-1}A\_i^\top)$. (See Algorithm 1 of the arXiv version of the paper)

For this equal-rank construction, every block has rank $r\_i=5$ with probability one and $R=\sum\_i r\_i=100$. The general initialization $w\_i^{(0)}=nr\_i/R$ therefore reduces to the uniform block initialization $w\_i^{(0)}=1$.

## Numerical evaluation

We evaluate the block update in float64 using a reduced QR factorization. For the blockwise row-scaled matrix $B=W^{r/2}A=QR$, we solve $R^\top X^\top=A^\top$ for $X=AR^{-1}$ and compute $w\_i^+=w\_i^r\lVert X\_i\rVert\_F^2$. This is algebraically the same block leverage update while avoiding direct extraction of very small row norms of $Q$.

## Residual and iteration counts

We measure progress with $R\_t=\max\_i\left|\log(w\_i^{(t+1)}/w\_i^{(t)})\right|$.

The main iteration count is $T\_{10^{-8}}$, the first update number for which $R\_t<10^{-8}$. From the same trajectory we also record the first crossings $T\_{10^{-4}}$ and $T\_{10^{-6}}$. Every run has a 10,000-iteration limit.

The final experiment contains $50\times15=750$ matrix/$p$ runs.

## Experiment results recorded

For each final matrix we record its rank, condition number, block ranks, and explicit block boundaries. For each matrix/$p$ run we record the three threshold crossings, final residual, terminal block weights and their extrema, block-weight sum defect, run status, and the full residual trajectory.

For each $p$, the main summary is the sample median of $T\_{10^{-8}}$ across the 50 matrices, together with the empirical 20th and 80th percentiles. We also retain the mean, sample standard deviation, minimum, maximum, and sample count. The threshold-sensitivity summary reports the medians of $T\_{10^{-4}}$, $T\_{10^{-6}}$, and $T\_{10^{-8}}$.

The main figure plots median iteration counts versus  $p$ on a linear axis. It shows the median and 20th/80th percentiles for $T\_{10^{-8}}$, plus the three median threshold curves.
